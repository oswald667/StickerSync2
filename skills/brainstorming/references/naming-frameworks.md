# Naming Frameworks — Nommer produits, features et marques

## Les 7 archétypes de nom

| Archétype | Exemples | Forces | Faiblesses |
|-----------|----------|--------|------------|
| **Descriptif** | Salesforce, WhatsApp | Clarté immédiate | Peu mémorable, hard to trademark |
| **Évocatif** | Amazon, Apple, Notion | Mémorable, riche en sens | Besoin d'éducation marché |
| **Acronyme** | IBM, NASA, SAP | Court, professionnel | Froid, générique |
| **Fondateur** | Ford, Tesla, Dyson | Confiance, authenticité | Dépend d'une personne |
| **Inventé** | Kodak, Xerox, Slack | Unique, trademark facile | Apprentissage nécessaire |
| **Analogie** | Safari, Bolt, Stripe | Ancré dans une métaphore | Peut limiter la perception |
| **Hybride** | Pinterest, Instagram | Équilibre clarté/originalité | Complexe à trouver |

## Processus de naming en 5 étapes

### 1. Définir le territoire sémantique
Lister les mots-clés qui décrivent :
- Ce que le produit **fait** (fonction)
- Ce qu'il **fait ressentir** (émotion)
- Ce qu'il **représente** (valeurs)
- Son **contexte d'usage** (quand, où, par qui)

### 2. Expansion — 3 techniques
**Associations directes** : mots liés au territoire
**Translations** : chercher dans d'autres langues (latin, grec, langues nordiques, japonais)
**Métaphores** : objets/animaux/phénomènes qui partagent la même essence

### 3. Génération — Combinaisons
- Mot A + Mot B (composé)
- Préfixe / Suffixe sur un mot existant
- Troncation d'un mot long
- Fusion phonétique (blend) : ex. "Pinterest" = Pin + Interest

### 4. Filtrage — 5 critères
1. **Prononçable** : se dit facilement dans la langue cible
2. **Mémorisable** : retenu après une seule écoute
3. **Disponible** : domaine .com + trademark vérifiable
4. **Scalable** : ne limite pas la croissance future du produit
5. **Positif** : aucune connotation négative dans les langues cibles

### 5. Test
- "Tu peux m'épeler ça ?" → test de mémorisation phonétique
- Recherche Google du nom seul → vérifier la pollution
- Test auprès de 5 personnes du persona cible : quelle image ça évoque ?

## Nommer une feature — Règles rapides

- **Verbe + Nom** pour les actions : "Quick Reply", "Smart Compose"
- **Adjectif + Nom** pour les états ou modes : "Focus Mode", "Dark Theme"
- Éviter les noms trop génériques ("Notifications", "Settings") quand la feature est distinctive
- Les noms en interne (code) ≠ noms utilisateurs : choisir les deux indépendamment
